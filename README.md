## Run Locally

This is a static website, so no Python environment or backend server is required to view the portfolio.

```bash
git clone https://github.com/yashchaudhari372-lab/yash-portfolio.git
cd yash-portfolio
```

Open `index.html` in your browser. For a local development server, you can use the **Live Server** extension in VS Code.

## Deployment

The portfolio is hosted on **Netlify**.

To deploy your own copy:

1. Fork or clone this repository.
2. Create a Netlify site and connect your GitHub repository.
3. Configure the publish directory as the repository root (`.`) for this static site.
4. Deploy and verify the website, asset paths, and contact form.

**Live site:** https://yash-chaudhari-portfolio.netlify.app/
